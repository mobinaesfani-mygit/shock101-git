# Echo-lite

## What is it?

Echo-lite is a simple Python program that repeats the user's message.

It checks if the input is empty and asks the user to enter a message.

## How to run?

Run the program with:
```bash
uv run python echo_lite.py
```
## Example

Input:
```text
Hello
```
Output:
```text
Test passed!
You: Hello
OK
Echo: Hello
```
